1. MODULE OVERVIEW & MINISTRY PURPOSE
================================================================================
The "Schedule" module (AdminPromiseCalendar) is the visual master planner for
a church's daily spiritual touchpoint: the Daily Promise. 

In the WeChristian ecosystem, thousands of believers start their day by opening
the mobile app to read God's daily word, accompanied by Telugu audio, biblical
commentaries, and custom graphic banners. If a date is missing its promise,
members receive fallback content or an unpopulated feed.

The Schedule calendar solves this by giving church leadership a bird's-eye view
of the entire month at a single glance:
  - Instantly reveals gaps where no promise has been scheduled ("Missing" in red).
  - Highlights drafts in preparation ("Draft" in amber).
  - Validates scheduled and published promises ("OK" in vibrant green).
  - Gives prominent visual priority to today's date with a glowing golden border.
  - Allows 1-tap navigation to instantly create or edit any date's promise.

3. MONTHLY CALENDAR MATRIX & LAYOUT CALCULATION
================================================================================
To dynamically generate an accurate calendar grid for any month without
external heavy calendar dependencies, `AdminPromiseCalendar.tsx` executes
native JavaScript date mathematics:

  1. First Day Offset:
     ```typescript
     const firstDay = new Date(year, month, 1).getDay();
     ```
     Yields an integer (0 for Sunday, 1 for Monday... 6 for Saturday).
     The UI renders `firstDay` empty placeholder cells (`calDay` with no text)
     to shift day 1 to its exact weekday column.

  2. Days In Month:
     ```typescript
     const daysInMonth = new Date(year, month + 1, 0).getDate();
     const days = Array.from({ length: daysInMonth }, (_, i) => i + 1);
     ```
     Calculates whether the month has 28, 29, 30, or 31 days and maps over them.

  3. Trailing Cell Alignment:
     ```typescript
     const totalGridCells = firstDay + daysInMonth;
     const trailingEmptyDays = totalGridCells % 7 === 0 ? 0 : 7 - (totalGridCells % 7);
     ```
     Renders invisible empty placeholder cells at the end of the month so the
     final row maintains equal cell widths under `flexWrap: 'wrap'` and
     `justifyContent: 'space-between'`.

5. 1-TAP DATE JUMP & DIRECT PROMISE EDITING WORKFLOW
================================================================================
Tapping any date cell initiates a seamless transition directly into the promise
authoring studio:

  ```typescript
  onPress={() => { 
    setEditingData(promise || { date: dStr }); 
    if (setTabByName) {
      setTabByName('New Promise');
    } else {
      setActiveTab(3); // Fallback to AdminPromiseEditor
    }
  }}
  ```

  Scenario A: Tapping a "Missing" Date (e.g. October 18)
    1. System packages `{ date: '2026-10-18' }` into `setEditingData`.
    2. Switches tab to `AdminPromiseEditor`.
    3. The editor initializes with the target date pre-selected as October 18, 2026.
    4. Admin selects scripture, writes title/explanation, picks poster theme,
       and hits Save.
    5. Upon returning to Schedule, October 18 instantly flips from Rose to Green!

  Scenario B: Tapping an Existing "Draft" or "Published" Date
    1. System packages the full existing promise document into `setEditingData`.
    2. Switches tab to `AdminPromiseEditor`.
    3. All existing text, audio URL, Telugu fonts, and bible verses load into the
       editor fields.
    4. Admin makes changes or approves draft for publishing.

6. TRAILING ALIGNMENT & RESPONSIVE PERCENTAGE GRID
================================================================================
Mobile devices have diverse screen resolutions (from compact 360px phones to
600px+ foldables and tablets).

To prevent broken row wraps, `AdminPromiseCalendar` uses strict percentage math:
  - Header Width: `13.5%` per weekday (`7 * 13.5% = 94.5%`, remaining 5.5%
    auto-spaced via `space-between`).
  - Cell Width: `13.5%` with `height: 52px`.
  - Border Radius: `10px` with centered alignment.
  - Trailing cells render with `opacity: 0` to preserve mathematical grid structure.

7. DATA RETRIEVAL & MONTH CACHING ARCHITECTURE
================================================================================
When the calendar screen mounts, it queries Firestore for promises belonging to
the active month:

  ```typescript
  const now = new Date();
  const data = await FirestoreService.getCalendarData(
    now.getFullYear(), 
    now.getMonth() + 1
  );
  ```

  Firestore Query Logic:
    - Filters by active church ID: `churchId == activeChurch.id`
    - Date string range filter:
      `date >= '2026-10-01'` and `date <= '2026-10-31'`
    - Orders by date ascending.
  
  Returns an array of promise objects containing:
    `id`, `date`, `title`, `verse`, `reference`, `status`, `thumbnailUrl`.

9. SYNCHRONIZATION WITH DAILY PROMISE CAROUSEL
================================================================================
In `AdminChurchSettings`, churches have the option:
  `Use WeChristian Daily Promise` (YES / NO)

  - If YES: The app displays the centralized WeChristian 4-time verse carousel
    (Morning, Afternoon, Evening, Night).
  - If NO: The app strictly uses the church's custom promise scheduled in this
    calendar for that date.

Even when centralized verses are enabled, scheduled custom promises are featured
prominently in the church's Daily Spiritual Feed, making calendar maintenance
essential for church member engagement.

================================================================================
10. ADMIN TIPS FOR PROACTIVE MINISTRY CONTENT SCHEDULING
================================================================================
1. The "Month-Ahead" Routine:
   Pastors and media teams should open the Schedule calendar on the 25th of
   every month and batch-schedule promises for the upcoming 30 days.

2. Using AI Sermon Assistant With Schedule:
   Key themes from Sunday sermons can be broken into 5 daily promise thoughts
   for the upcoming week using the AI Sermon Assistant, and scheduled directly
   across Monday to Friday in the calendar.

3. Monitoring Missed Days:
   Glance at the calendar every Friday afternoon. If Saturday or Sunday cells
   show in Rose ("Missing"), tap them immediately to ensure weekend worshippers
   receive their morning promise without delay.
