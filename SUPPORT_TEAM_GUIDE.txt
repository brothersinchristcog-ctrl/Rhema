1. MODULE OVERVIEW & PASTORAL ASSISTANCE MISSION
================================================================================
The "Support Team" module (AdminSupportTeam) is the dedicated pastoral care,
onboarding, and technical assistance hub built directly into the WeChristian
administration console.

Recognizing that church pastors, elders, and volunteer media teams are often
serving in high-pressure environments, this module removes all barriers to
receiving immediate help. Instead of filing robotic support tickets or waiting
in multi-day queues, church administrators have instant, personal access to the
founding engineers and ministry specialists behind WeChristian:
  - 1-Tap WhatsApp Support: Connects directly with support engineers via chat.
  - 1-Tap Direct Voice Calling: Immediately dials personal helpline numbers.
  - Digital Helpdesk: Direct links to email support, video tutorials, and web resources.

4. 1-TAP ACTION WORKFLOWS (WHATSAPP & VOICE DIALER)
================================================================================
A. WHATSAPP 1-TAP TRIGGER
   ```typescript
   const handleWhatsApp = (phone: string) => {
     const message = encodeURIComponent(
       'Hello WeChristian Support Team, I need help with the WeChristian app.'
     );
     const url = `https://wa.me/91${phone}?text=${message}`;
     Linking.openURL(url);
   };
   ```
   - Automatically prefixes India country code (`91`).
   - Pre-populates a polite opening greeting in the chat input.
   - Bypasses the need for pastors to save new contacts into their phone address
     book before asking a question.

B. NATIVE VOICE DIALER TRIGGER
   ```typescript
   const handleCall = (phone: string) => {
     const url = `tel:+91${phone}`;
     Linking.openURL(url);
   };
   ```
   - Dispatches a native `tel:` system intent directly to the Android or iOS
     dialer app with the full telephone number pre-filled.

7. DEEP-LINK INTENT ARCHITECTURE & URL PROTOCOL SCHEMES
================================================================================
Protocol Schemes Executed by the Screen:
  - WhatsApp: `https://wa.me/{phone}?text={encodedText}`
  - Voice Call: `tel:+91{phone}`
  - Email: `mailto:{address}?subject={encodedSubject}&body={encodedBody}`
  - Web: `https://wechristian.app`
  - YouTube: `https://www.youtube.com/@WeChristianApp`

All calls are protected with `.catch(err => console.error(err))` to prevent
app crashes on devices missing specific default handler apps.
