1. MODULE OVERVIEW & PASTORAL PURPOSE
================================================================================
The Celebrations module in WeChristian is an intelligent pastoral care system that 
empowers church leaders to never miss a member's milestone.

Core Milestone Categories Supported:
1. Birthdays: Celebrating every member's gift of life, with automatic age milestone 
   computation (e.g., "Turning 25 yrs old").
2. Wedding Anniversaries: Honoring holy matrimony and blessed marriages across church 
   families, grouping married couples together.
3. Baptism Anniversaries: Celebrating spiritual rebirth, water baptism, and faith 
   milestones within the parish.

Dual Operational Modes:
* Fast Automation ("Auto-Send All"): On busy mornings (e.g., Sunday before service), 
  the Pastor or secretary can tap "Auto-Send All" to dispatch blessings to all 
  celebrating members in a single click.
* Deep Personalization ("Prepare Wish"): When giving personal pastoral attention, 
  leaders can design a stunning, branded graphic greeting card, attach bilingual 
  Scripture blessings (Telugu or English), and send it with personalized greetings 
  directly to WhatsApp or Push Notifications.

2. NAVIGATION & SCREEN STATE MACHINE
================================================================================
The Celebrations module runs on a centralized state-machine architecture inside 
`AdminCelebrations.tsx` controlling the following sequential views:

[Celebrations Tile in Admin Dashboard]
           |
           v
    'dashboard' (Root timeline, metrics, filters, member list)
           |
     (Tap Member)
           |
           v
     'details' (Member profile, turning age, parent reference phone)
           |
    (Tap "Prepare Wish")
           |
           v
   'personalize' <---------------------------------------------------+
      |      |      |      |                                         |
      |      |      |      +---> 'photoPicker' (Upload custom photo) -+
      |      |      |                                                |
      |      |      +----------> 'versePicker' (English / Telugu) ---+
      |      |                                                       |
      |      +-----------------> 'themePicker' (Select theme) -------+
      |                                |                             |
      |                                +---> 'customTheme' ----------+
      v
   'preview' (Full-screen digital banner preview)
      |
      v
  'whatsapp' (WhatsApp bubble simulation, ViewShot snapshot & multi-share)
      |
      +---> Send via WhatsApp (Native intent / deeplink)
      +---> Send via Push Notification (Firestore broadcast)
      |
      v
   'confirm' (Animated celebration checkmark, gallery & clipboard notice)

3. CELEBRATIONS DASHBOARD (AdminCelebrations.tsx)
================================================================================
The primary control deck showing upcoming milestones and celebration statistics.

3.1 Header & Hero Navigation
----------------------------
* Back Button: Left chevron button returning to the main Admin Dashboard (`setActiveTab(0)`).
* Header Titles: Bold "Celebrations" title with subtitle "Manage birthdays & anniversaries".

3.2 "This Season" Stats Card
----------------------------
A high-contrast card displaying real-time metrics across all church records:
* TOTAL RECORDS: Total number of celebrations recorded in the database.
* TODAY: Total number of members celebrating a milestone today.
* THIS WEEK: Total number of members celebrating within the next 7 days.
Automatically parses `dob`, `anniversaryDate`, and `baptismDate` fields to detect 
dates falling within the rolling 7-day window.

3.3 Date Range Filter Buttons
-----------------------------
A horizontal scrolling bar offering 6 instant filter views:
1. "Today": Shows only members celebrating on the current date. Automatically enables 
   the "Auto-Send All" button.
2. "Upcoming": Shows all future celebrations starting from tomorrow.
3. "Week": Shows celebrations occurring in the next 7 calendar days.
4. "Month": Shows celebrations occurring within the current calendar month.
5. "Past": Shows completed celebrations earlier in the year.
6. "All": Shows all celebration records across the entire year.

3.4 Category Filter Pills
-------------------------
Horizontal pills with distinct color-coding to isolate milestone types:
* "Birthday" (Warm Gold: `#F3E4B6` bg, `#B88A2E` text)
* "Wedding Anniversary" (Royal Lavender: `#E2E5F2` bg, `#455490` text)
* "Baptism Anniversary" (Mint Emerald: `#DDF1E7` bg, `#358B6D` text)
Tapping any category filters the list. Tapping the active category resets to "All".

3.5 Embedded Member List Container
----------------------------------
Embeds the dynamic `AdminCelebrationsList` component, passing the active date filter, 
category filter, and member selection callback.

4. MEMBER CELEBRATION DIRECTORY (AdminCelebrationsList.tsx)
================================================================================
Displays the filtered list of members celebrating milestones.

4.1 Search Engine & Dynamic Matching
------------------------------------
* Search Input Box: Located at top with search icon. Real-time text filtering 
  matching member first name, middle name, or surname.
* Result Counter: Displays total count (e.g., "5 members found").

4.2 Member Card Anatomy
-----------------------
Each member card is rendered with rich metadata:
* Avatar Component:
  - If a valid photo URL exists (`profilePhoto`, `photoUrl`, `ProfilePhoto`, etc.), 
    renders the high-resolution profile picture with error handling.
  - If no photo exists, generates a colored circular badge using the member's 
    two-letter uppercase initials and a deterministic color hash (`#734062`, `#1A4F5B`, 
    `#42518E`, `#D97736`).
* Member Full Name: Bold heading truncated cleanly if long.
* Milestone Tag: Colored badge displaying `BIRTHDAY`, `WEDDING ANNIVERSARY`, or 
  `BAPTISM ANNIVERSARY`.
* Metadata String: Date string (e.g., "Jul 15") and calculated age milestone 
  (e.g., "• 28 yrs").

4.3 "Auto-Send All" Mass Push Broadcast Engine
----------------------------------------------
* Only visible when the "Today" date filter is active and at least one member is celebrating.
* Button: Deep blue pill button with paper-airplane Send icon: "Auto-Send All".
* When tapped, iterates through all celebrating members today and dispatches an 
  individualized in-app celebration push broadcast to each member's registered device.

4.4 Confirmation & Success Modal Dialogs
----------------------------------------
* Confirmation Modal:
  - Heading: "Confirm Auto-Send"
  - Body: "Are you sure you want to automatically send push notifications to all X 
    members celebrating today?"
  - Buttons: "Cancel" (dismisses) and "Send to All" (executes loop with loading indicator).
* Success Modal:
  - Animated emerald checkmark icon.
  - Heading: "Success!"
  - Body: "Automated wishes sent to X members!"
  - "Done" button to dismiss.

6.4 Auto-Generated Greeting Message & Custom Text Editor
--------------------------------------------------------
Pre-populates an affectionate Christian greeting tailored to the milestone:
* Birthday Default: "Dear [Name], wishing you a joy-filled birthday surrounded by 
  God's love and grace. May this new year of life be your best yet!"
* Wedding Anniversary Default: "Dear [Name], wishing you a joyful Wedding Anniversary!

10. GREETING CARD PREVIEW & DISPATCH
================================================================================
Where the visual banner is rendered and dispatched to external channels.

10.1 Card Visual Layout & SVG Frame (AdminCelebrationsPreview.tsx)
------------------------------------------------------------------
* Top Navigation: Back and Edit buttons.
* Graphic Frame (400 x 500 ratio):
  - Church Name Banner (e.g., "Grace Community Church" or "WeChristian").
  - Circular framed photo with triple white border (or full photo background).
  - Milestone Category Title (e.g., "Happy Birthday").
  - Member Name in bold typography.
  - Heartfelt greeting message.
  - Scripture blessing in italics with reference citation.
  - Signature footer: "Sent with love".
* Action Buttons:
  - "Edit": Returns to Personalize screen for quick adjustments.
  - "Continue": Advances to the WhatsApp Delivery Studio.

10.2 WhatsApp Delivery Studio (AdminCelebrationsWhatsAppPreview.tsx)
--------------------------------------------------------------------
Simulates an exact WhatsApp chat conversation thread:
* WhatsApp Contact Bar: Shows member's profile avatar, name, and telephone number.
* Simulated Chat Bubble:
  - Shows the complete generated graphic greeting card inside the message bubble.
  - Formatted WhatsApp text caption:
    "Praise the Lord!
     [Personalized Greeting Message]
     "[Scripture Verse]" — [Scripture Reference]
     With Love ❤️
     [Church Name]"
  - Timestamp with double-check (✓✓) delivery receipt mark.

10.3 High-Resolution ViewShot Snapshot Engine
---------------------------------------------
When tapping "Send" or "WhatsApp":
1. `ViewShot.capture()` renders the card frame off-screen at full native pixel resolution.
2. Generates an uncompressed high-resolution PNG image stored in the app's cache directory.
3. Automatically saves a copy to the mobile device's native Media Library / Photo Gallery 
   so the church always has an archive of cards sent.
4. Automatically copies the complete caption text to the device Clipboard as a 
   guaranteed backup.

10.4 4-Tier WhatsApp Dispatch Pipeline
--------------------------------------
The system utilizes a 4-tier fallback mechanism to guarantee delivery:
* Tier 1: Direct WhatsApp Intent (`Share.shareSingle` with `Share.Social.WHATSAPP` or 
  `WHATSAPPBUSINESS`):
  - Detects if standard WhatsApp (`com.whatsapp`) or WhatsApp Business (`com.whatsapp.w4b`) 
    is installed on Android.
  - Dispatches both the card image AND the pre-filled text caption directly into 
    the member's chat thread.
* Tier 2: Native System Share Chooser (`Share.open`):
  - If direct single intent fails, opens the native OS sharing sheet with image + caption.
* Tier 3: Expo Sharing (`Sharing.shareAsync`):
  - If native share fails, uses Expo's file sharing bridge.
* Tier 4: Universal Deeplink Fallback (`https://wa.me/[phone]?text=[encodedText]`):
  - If image sharing is blocked or refused, opens WhatsApp web/app deeplink with the 
    complete formatted message text pre-loaded in the composer.

10.5 In-App Push Notification Broadcast Dispatch
------------------------------------------------
Beside the WhatsApp button is the "Send Push" button:
1. Uploads the greeting card image to Firebase Storage (`celebrations/image_{timestamp}.jpg`).
2. Calls `FirestoreService.createNotificationBroadcast()` targeting the specific member's 
   phone number and device token.
3. Triggers an in-app celebration alert on the member's smartphone with the card banner.

12. DATABASE SCHEMA & FIRESTORE INTEGRATION
================================================================================
Celebrations data is aggregated from members and church collections in Firestore:

1. Member Document Date Fields:
   - `dob` / `Birthdate`: Member's birth date (format: "YYYY-MM-DD" or "MM/DD/YYYY").
   - `anniversaryDate` / `Anniversary_Date__c`: Marriage wedding anniversary.
   - `baptismDate` / `Baptism_Date__c`: Water baptism spiritual milestone.

2. Phone Routing Fields:
   - `phone` / `MobilePhone`: Primary member smartphone number.
   - `referencePhone`: Parent or guardian phone number for child accounts.
   - `isReferencePhone`: Boolean flag indicating child account routing.

3. Custom Themes Storage:
   - Path: `churches/{churchId}`
   - Field: `customThemes` (Array of objects)
   - Object Structure:
     {
       id: "custom_1727500000000",
       title: "Youth Anniversary",
       color: "#1E2A63",
       imageUrl: "https://firebasestorage.googleapis.com/.../custom_xxx.jpg",
       isCustom: true
     }

4. Celebration Notification Broadcasts:
   - Collection: `notification_broadcasts`
   - Payload:
     {
       title: "🎂 Happy Birthday, John Doe!",
       content: "Praise the Lord!...",
       date: "October 14",
       type: "celebration",
       targetChurchId: "church_123",
       targetPhone: "+919876543210",
       imageUrl: "https://firebasestorage...",
       silent: false
     }

13. TROUBLESHOOTING & FREQUENTLY ASKED QUESTIONS
================================================================================
1. Why did the birthday wish send to the parent instead of the child?
   - In WeChristian, kids and youth without personal mobile numbers have their 
     household parent's number flagged as `referencePhone`. The app intentionally 
     routes wishes to parents so children never miss out on church blessings.

2. What if WhatsApp is not installed on the tablet or device?
   - The app detects this and gracefully falls back to the system share dialog, 
     direct web link (`wa.me`), or in-app Push Notifications.

3. Can I use Telugu Bible verses on the card?
   - Yes! Tap the Bible Verse card in the Personalize Studio and switch the top 
     toggle from "English" to "తెలుగు (Telugu)". Over 90 curated Telugu Scripture 
     verses are pre-translated and ready to use.

4. Where are captured card images stored on my phone?
   - Cards are automatically saved to your phone's native Gallery / Camera Roll 
     under the album "WeChristian" or "Pictures".
